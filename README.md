# سیستم محاسبه سود سرمایه‌گذاری (برنامه‌ی دسکتاپی — ویندوز و مک)

## نصب (یک‌بار)
1. پایتون ۳٫۹ یا بالاتر از python.org (نصب‌کننده‌ی رسمی، Tkinter را همراه دارد؛ مک با Homebrew: `brew install python-tk`)
2. در پوشه‌ی برنامه: `pip install openpyxl`   (مک: `pip3`)

## اجرا
    python app.py          (مک: python3 app.py)
پنجره‌ی برنامه باز می‌شود. همه‌چیز محلی است و به اینترنت نیاز ندارد.

## شروع با اطلاعات اکسل فعلی
تب «تنظیمات» ← «انتخاب فایل و ورود اطلاعات»، یا:  `python app.py import "فایل.xlsm"`

## قاعده‌ی سررسید
سررسیدها همیشه سالگرد ماهانه‌ی **اولین تاریخ سرمایه‌گذاری** هستند (تقویم شمسی؛ اگر روز در ماه بعد نبود، آخرین روز ماه، و ماه بعدش دوباره روز اصلی). تاریخ واقعی پرداخت فقط ثبت می‌شود و سررسیدها را جابه‌جا نمی‌کند. سود هر دوره تا روز سررسید محاسبه می‌شود.

## یادآور
- هنگام باز کردن برنامه، پنجره‌ی یادآور سررسید گذشته/امروز/فردا نشان داده می‌شود (اگر برنامه روزها باز بماند، با عوض شدن روز دوباره).
- بدون باز کردن برنامه: `python app.py remind` فهرست را چاپ و اعلان دسکتاپ می‌دهد. زمان‌بندی:
  - ویندوز: Task Scheduler ← Create Basic Task ← Daily ← Start a program: `python` ، آرگومان: `"C:\مسیر\app.py" remind`
  - مک: `crontab -e` و خط `0 9 * * * cd /مسیر/investment_app && python3 app.py remind`

## داده‌ها
همه‌چیز در `data/invest.db` (SQLite) کنار برنامه. برای پشتیبان‌گیری همین فایل را کپی کنید، یا از تب تنظیمات پشتیبان اکسل بگیرید.
