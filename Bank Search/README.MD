# جستجوی مقدار در فایل اکسل (چند شیت) / Excel Multi-Sheet Value Search

اسکریپتی پایتون برای جستجوی یک عبارت (عدد، متن و ...) در تمام شیت‌های یک فایل اکسل.  
نتایج جستجو به‌صورت **شیت‌های جداگانه** در فایل خروجی ذخیره می‌شوند؛ یعنی هر شیت از فایل ورودی که حداقل یک ردیف منطبق داشته باشد، در فایل خروجی به‌صورت یک شیت با همان نام ظاهر می‌شود.  
این ابزار اعداد فارسی/عربی را به انگلیسی تبدیل می‌کند و جستجو را بدون حساسیت به بزرگی/کوچکی حروف انجام می‌دهد.

---

## پیش‌نیازها

- Python 3.7 یا بالاتر
- کتابخانه‌های مورد نیاز:

```bash
pip install pandas openpyxl
```

---

## نصب

1. کد را در یک فایل پایتون ذخیره کنید (مثلاً `excel_search.py`).
2. کتابخانه‌های لازم را نصب کنید (دستور بالا).
3. مسیر فایل ورودی، خروجی و عبارت جستجو را در کد تنظیم کنید.

---

## نحوه اجرا

```bash
python excel_search.py
```

پس از اجرا، برنامه تمام شیت‌های فایل ورودی را بررسی می‌کند و در صورت یافتن موارد منطبق، آن‌ها را در فایل خروجی ذخیره می‌کند.

---

## تنظیمات

در ابتدای کد، سه متغیر اصلی وجود دارد که باید تنظیم کنید:

```python
input_file = "/Users/rasoulpourfeiz/Desktop/Bank.xlsx"
output_file = "/Users/rasoulpourfeiz/Desktop/Search_Results.xlsx"
query = "730120020000005807601476"
```

| متغیر | توضیح |
|---|---|
| `input_file` | مسیر فایل اکسل ورودی |
| `output_file` | مسیر فایل اکسل خروجی |
| `query` | عبارت جستجو (می‌تواند شامل اعداد فارسی یا انگلیسی باشد) |

---

## نحوه کار

1. **تبدیل اعداد فارسی به انگلیسی:**  
   تابع `persian_to_english` اعداد فارسی (۰ تا ۹) را به معادل انگلیسی (0 تا 9) تبدیل می‌کند. این کار روی `query` و تمام مقادیر سلول‌ها اعمال می‌شود.

2. **بارگذاری فایل اکسل:**  
   با استفاده از `openpyxl` فایل ورودی باز می‌شود و همهٔ شیت‌ها یکی‌یکی پردازش می‌شوند.

3. **جستجو در هر ردیف:**  
   برای هر شیت، یک DataFrame ساخته می‌شود. سپس تابع `row_matches` هر ردیف را بررسی می‌کند. اگر مقدار `query` در هر یک از سلول‌های ردیف پیدا شود (با `re.search` و بدون حساسیت به حروف بزرگ/کوچک)، آن ردیف به‌عنوان منطبق علامت‌گذاری می‌شود.

4. **جمع‌آوری نتایج:**  
   ردیف‌های منطبق هر شیت در یک DataFrame جداگانه ذخیره می‌شوند. یک ستون اضافه به نام `Sheet_Name` نیز به هر DataFrame اضافه می‌شود که نام شیت مبدأ را نشان می‌دهد.

5. **ذخیره خروجی:**  
   در نهایت، برای هر شیت که داده‌ای منطبق داشته، یک شیت جدید در فایل خروجی با **همان نام شیت اصلی** ایجاد می‌شود و داده‌های منطبق در آن نوشته می‌شوند.

---

## خروجی

- یک فایل اکسل با نام دلخواه (پیش‌فرض: `Search_Results.xlsx`).
- شامل **چند شیت** به نام شیت‌های اصلی فایل ورودی که دادهٔ منطبق داشته‌اند.
- هر شیت شامل ردیف‌های منطبق همان شیت اصلی است.
- یک ستون اضافه به نام `Sheet_Name` در هر شیت وجود دارد که نام شیت مبدأ را نشان می‌دهد.
- اگر هیچ موردی پیدا نشود، فایل خروجی ساخته نمی‌شود و پیام مناسب چاپ می‌شود.

---

## مثال

فرض کنید فایل ورودی `Bank.xlsx` دارای سه شیت به نام‌های `Accounts`، `Transactions` و `Cards` باشد.  
عبارت جستجو `730120020000005807601476` است. اگر این مقدار در دو شیت `Accounts` و `Cards` پیدا شود، فایل خروجی `Search_Results.xlsx` شامل دو شیت به نام‌های `Accounts` و `Cards` خواهد بود که هر کدام فقط ردیف‌های منطبق را در بر می‌گیرند.

---

## نکات مهم

- جستجو در **همهٔ شیت‌ها** انجام می‌شود.
- جستجو **بدون حساسیت به بزرگی/کوچکی حروف** است (`re.IGNORECASE`).
- از `re.escape` برای امن کردن عبارت جستجو استفاده شده تا کاراکترهای خاص regex مشکلی ایجاد نکنند.
- اعداد فارسی/عربی خودکار به انگلیسی تبدیل می‌شوند.
- اگر هیچ موردی پیدا نشود، پیام «هیچ داده‌ای پیدا نشد» چاپ می‌شود و فایل خروجی ساخته نمی‌شود.
- در صورت خالی بودن یک شیت، از آن رد می‌شود.
- فرمت فایل‌های ورودی و خروجی باید `.xlsx` باشد.
- در این نسخه، نتایج به‌صورت **شیت‌های جداگانه** ذخیره می‌شوند (نه در یک شیت واحد).

---

## سفارشی‌سازی

- **تغییر عبارت جستجو:** مقدار `query` را تغییر دهید.
- **جستجوی جزئی:** به‌طور پیش‌فرض جستجو به‌صورت «شامل بودن» است. اگر می‌خواهید تطبیق دقیق باشد، از `re.fullmatch` استفاده کنید.
- **حساس به حروف:** در صورت نیاز، `re.IGNORECASE` را حذف کنید.
- **ذخیره در یک شیت واحد:** می‌توانید نتایج را با `pd.concat` ادغام کنید و در یک شیت بنویسید.

## کد کامل

```python
import pandas as pd
import openpyxl
import re

# ==== مسیر فایل ورودی و خروجی ====
input_file = "/Users/rasoulpourfeiz/Desktop/Bank.xlsx"
output_file = "/Users/rasoulpourfeiz/Desktop/Search_Results.xlsx"

# ==== عبارت جستجو ====
query = "730120020000005807601476"  # می‌تواند شامل اعداد فارسی یا انگلیسی باشد

# ==== تابع تبدیل اعداد فارسی به انگلیسی ====
def persian_to_english(s):
    if pd.isna(s):
        return s
    s = str(s)
    persian_nums = "۰۱۲۳۴۵۶۷۸۹"
    english_nums = "0123456789"
    for p, e in zip(persian_nums, english_nums):
        s = s.replace(p, e)
    return s

# ==== تبدیل query به انگلیسی ====
query = persian_to_english(query)

# ==== باز کردن workbook ====
wb = openpyxl.load_workbook(input_file, data_only=True)

# ==== لیستی برای نگهداری شیت‌های matched به همراه نام شیت ====
matched_sheets = []

# ==== حلقه روی همه شیت‌ها ====
for sheet_name in wb.sheetnames:
    ws = wb[sheet_name]
    data = ws.values
    
    try:
        cols = next(data)
    except StopIteration:
        continue  # شیت خالی است، رد شود

    df = pd.DataFrame(data, columns=cols)

    # ==== تابع بررسی match برای هر ردیف ====
    def row_matches(row):
        for val in row:
            if pd.isna(val):
                continue
            val_str = persian_to_english(str(val))
            if re.search(re.escape(query), val_str, re.IGNORECASE):
                return True
        return False

    # پیدا کردن ردیف‌های match و ایجاد یک کپی واضح
    matched_df = df[df.apply(row_matches, axis=1)].copy()
    
    # اگر داده‌ای پیدا شد، به لیست اضافه کن
    if not matched_df.empty:
        matched_df["Sheet_Name"] = sheet_name  # اضافه کردن نام شیت به عنوان یک ستون
        matched_sheets.append((sheet_name, matched_df))

# ==== اگر حداقل یک شیت با داده پیدا شد، فایل خروجی ایجاد کن ====
if matched_sheets:
    # ایجاد یک ExcelWriter و اضافه کردن هر شیت
    with pd.ExcelWriter(output_file, engine='openpyxl') as writer:
        for sheet_name, matched_df in matched_sheets:
            matched_df.to_excel(writer, index=False, sheet_name=sheet_name)
            print(f"✅ نتایج برای شیت '{sheet_name}' ذخیره شد")
    print(f"✅ جستجو کامل شد! نتایج در {output_file} ذخیره شد")
else:
    print(f"❌ هیچ داده‌ای برای '{query}' پیدا نشد")
```
