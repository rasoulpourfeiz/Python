# محاسبه سود سپرده بانکی

این اسکریپت پایتون سود روزانه، ماهانه و سالانه یک سپرده بانکی را بر اساس مبلغ اصل و نرخ سود سالانه محاسبه می‌کند. اعداد با جداکننده هزارگان و دو رقم اعشار نمایش داده می‌شوند.

---

## نحوه اجرا

```bash
python interest_calculator.py
```

سپس برنامه دو مقدار زیر را از شما می‌پرسد:

- مبلغ سپرده بانکی (به ریال)
- نرخ سود سالانه (به درصد)

---

## ورودی‌ها

| ورودی | نوع | توضیح |
|---|---|---|
| مبلغ سپرده | عدد اعشاری | مبلغ اصل سپرده به ریال |
| نرخ سود | عدد اعشاری | نرخ سود سالانه به درصد (مثلاً 18 برای ۱۸٪) |

---

## خروجی

برنامه سه خط خروجی چاپ می‌کند:

- **سود روزانه**: سود یک روز بر اساس نرخ سالانه.
- **سود ماهانه**: سود یک ماه (۳۰ روز).
- **سود سالانه**: سود یک سال (۳۶۵ روز).

اعداد با جداکننده هزارگان (کاما) و دو رقم اعشار نمایش داده می‌شوند.

---

## فرمول محاسبه

فرمول‌های استفاده‌شده به‌صورت زیر است:

```text
سود روزانه = مبلغ سپرده × نرخ سود / 365
سود ماهانه = سود روزانه × 30
سود سالانه = سود روزانه × 365
```

توجه: نرخ سود ورودی به درصد است و قبل از محاسبه بر ۱۰۰ تقسیم می‌شود.

---

## مثال

فرض کنید:

- مبلغ سپرده: `100,000,000` ریال
- نرخ سود سالانه: `18` درصد

خروجی برنامه به‌صورت زیر خواهد بود:

```text
سود روزانه: 49,315.07 ریال
سود ماهانه: 1,479,452.05 ریال
سود سالانه: 18,000,000.00 ریال
```

(اعداد گرد شده‌اند.)

---

## نکات

- در محاسبه سود ماهانه از ۳۰ روز استفاده شده است، نه تعداد واقعی روزهای ماه.
- در محاسبه سود سالانه از ۳۶۵ روز استفاده شده است (سال غیر کبیسه).
- نرخ سود باید به‌صورت درصد وارد شود (مثلاً `18` برای ۱۸ درصد، نه `0.18`).
- برنامه هیچ اعتبارسنجی روی ورودی‌ها انجام نمی‌دهد؛ در صورت وارد کردن مقادیر نامعتبر ممکن است خطا بدهد.

---

## کد کامل

```python
def calculate_interest(principal, rate):
    # محاسبه سود روزانه
    daily_interest = principal * rate / 365
    # محاسبه سود ماهانه
    monthly_interest = daily_interest * 30
    # محاسبه سود سالانه
    annual_interest = daily_interest * 365

    # نمایش اعداد با سه رقم جداشونده
    formatted_daily_interest = f"{daily_interest:,.2f}"
    formatted_monthly_interest = f"{monthly_interest:,.2f}"
    formatted_annual_interest = f"{annual_interest:,.2f}"

    return formatted_daily_interest, formatted_monthly_interest, formatted_annual_interest

# ورودی‌ها
principal_amount = float(input("لطفا مبلغ سپرده بانکی را وارد کنید (ریال): "))
interest_rate = float(input("لطفا نرخ سود را وارد کنید (درصد): ")) / 100

daily, monthly, annual = calculate_interest(principal_amount, interest_rate)

print(f"سود روزانه: {daily} ریال")
print(f"سود ماهانه: {monthly} ریال")
print(f"سود سالانه: {annual} ریال")
```
